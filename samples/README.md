# samples/

כאן יושבים קובצי הדוגמה **המקוריים** של המארגנים, לפני כל עיבוד.

- פורמטים נתמכים: PDF, JPEG, PNG. הסוג נקבע לפי תוכן הקובץ, לא לפי הסיומת.
- אפשר לשים תתי־תיקיות; הסריקה רקורסיבית.
- אין לערוך, לחתוך או לסובב כאן קבצים. כל עיבוד נכתב ל-`work/` בלבד.
- **כל התיקייה הזאת מוחרגת מ-Git** (חוץ מקובץ זה). אין להעלות טפסים לשום שירות.

העתיקו לכאן קודם שלושה טפסים שונים זה מזה, ואחרי שהתהליך ברור — הרחיבו ל-10–15.

בדיקה שהקבצים נקלטו:

```powershell
uv run pages list
```
