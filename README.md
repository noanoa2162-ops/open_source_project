# טופס למידע — מטפסי התחייבות לרשומות במערכת

האקתון AI קוד פתוח 2026, אתגר המעבדה המרכזית לנגיפים.

**מה המערכת עושה:**
1. גוררים טפסי התחייבות סרוקים, כמה שרוצים, תמונות ו/או PDF.
2. מודל ראייה (Claude) קורא כל טופס לבד.
3. כל ספק מסומן בכתום, עם סיבה כתובה.
4. מתקנים ומאשרים במקום.
5. **כל רשומה נשמרת במערכת**, ואפשר לחזור אליה, לחפש ולסנן. ייצוא ל-Excel, CSV או JSON, ו-API.

📄 **[סיכום: גישה, תוצאות, מגבלות, ומה נדרש למעבדה](docs/SUMMARY.md)** · [תוצאות מדידה](docs/EVALUATION.md) · [פריסה לענן](DEPLOYMENT.md)

## הרצה

```powershell
uv sync        # פעם אחת
uv run serve   # נפתח בדפדפן: http://127.0.0.1:8000
```

ב-`.env` צריך שורה אחת: `ANTHROPIC_API_KEY=sk-ant-...`. שאר ההגדרות ב-[.env.example](.env.example) הן אופציונליות.

**מומלץ: Tesseract**, לזיהוי דף שנסרק על הצד או הפוך. הוא מקומי וחינמי. בלעדיו המערכת עובדת, אבל דף מסובב נקרא מסובב.
- Windows: `winget install UB-Mannheim.TesseractOCR`
- Linux / Docker: `apt-get install tesseract-ocr` (כבר כלול ב-Dockerfile)

```

  └─> בדיקת סוג לפי בייטים, לכל קובץ בנפרד                files.py
  └─> רינדור כל עמוד, סיבוב (Tesseract) ויישור — מקומי     pages.py
  └─> תשובה שמורה לאותו דף? מוחזרת בחינם                    pipeline.py (work/read_cache)
  └─> Claude קורא כל עמוד לבד, לפי סכימה קשיחה             providers/claude_vision.py
        ההוראות למודל                                         prompts/extract_v4.md
  └─> כמה טפסים בעמוד → טופס לכל רשומה · עמוד המשך → מצורף  pipeline.py (read_page)
  └─> ספק של המודל → כתום · בדיקות תקינות → כתום עם סיבה    consensus.py, validators.py
  └─> נשמר מיד ב-SQLite (כל רשומה, כל תיקון)                db.py, store.py
  └─> בדיקה ותיקון במסך → "אישור הטופס"                      web/app.js
  └─> "רשומות במערכת": חיפוש, סינון, ייצוא                   web/records.js, GET /api/records
```

## כללים שהמערכת שומרת

- **מספרים הם מחרוזות.** אפסים מובילים נשמרים, גם בתא ב-Excel.
- **שדה שלא נמצא נשאר ריק ומסומן כתום.** לא מנחשים, וכל ספרה לא ודאית נכתבת `?`.
- **כתום = צריך בדיקה. ירוק = אדם אישר.** תא רגיל אינו טענת נכונות.
- **תאריך קבלה בלבד:** מחותמת "התקבל" או מכתב יד מתחת למספר המרכזי.
- **גורם שולח מרשימה סגורה.** שם שאינו ברשימה נשאר כפי שנקרא ומסומן.
- **ערכים מרובים נשמרים כולם.** באקסל: שורה לכל מספר התחייבות.
- **ערך שמתחיל ב-`=`, `+`, `-` או `@`** נכתב כטקסט ולא ירוץ כנוסחה.
- **עמוד אינו תמיד טופס.** כמה טפסים בעמוד מופרדים, ועמוד המשך מצורף לטופס שלפניו. שני המקרים מסומנים לבדיקה.
- **כל דפדפן רואה רק את הקליטות שלו** (cookie סודי). בפריסה ציבורית יש גם קוד גישה ותקרת עלות יומית.
- **תוכן המסמך הוא מידע, לא הוראה למודל.**

## מדידה

```powershell
uv run gold-draft                                              # טבלת האמת → מסך הבדיקה, לאישור אנושי
uv run evaluate --configs current,opus-medium,sonnet-high      # תוכנית ועלות משוערת, בלי קריאות
uv run evaluate --configs current,opus-medium,sonnet-high --yes
```

המדד הראשי הוא **שגיאות שקטות**: ערך שגוי בלי סימון כתום. התוצאות נכתבות ל-[docs/EVALUATION.md](docs/EVALUATION.md).

## בדיקות

```powershell
uv run pytest -q
```

הבדיקות רצות בלי רשת ובלי עלות, והמודל מדומה. הן מכסות:
- זיהוי סוג קובץ, סיבוב ויישור
- אפסים מובילים, תאריכים ובדיקות תקינות
- רשימה סגורה וערכים מרובים
- פיצול וחיבור עמודים
- שמירה וטעינה מהמסד, חיפוש וסינון
- בידוד בין sessions, קוד גישה ו-CSRF
- התנגשות עריכות, ייצוא Excel/CSV/JSON וניטרול נוסחאות
- כשל ספק ותקרת תקציב
