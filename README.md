# טופס למידע — מטפסי התחייבות לאקסל

דמו להאקתון AI קוד פתוח, אתגר המעבדה המרכזית לנגיפים.

**מה המערכת עושה:** גוררים טפסי התחייבות סרוקים — כמה שרוצים, תמונות ו/או PDF →
המודל קורא כל אחד מהם →
טבלה בעברית עם סימון כתום לכל מה שדורש בדיקה → תיקון במקום → הורדת Excel.

## הרצה

```powershell
uv sync        # פעם אחת
uv run serve   # נפתח אוטומטית בדפדפן ב-http://127.0.0.1:8000
```

**מומלץ: Tesseract**, לזיהוי דף שנסרק על הצד או הפוך, וסיבוב שלו לפני הקריאה. הוא
מקומי וחינמי, ומשמש רק לכיוון הדף. בלעדיו המערכת עובדת, אבל דף מסובב נקרא מסובב,
והתקריבים עלולים לצאת במקום הלא נכון.
- Windows: `winget install UB-Mannheim.TesseractOCR`, או המתקין מ-
  github.com/UB-Mannheim/tesseract.
- Linux / Docker: `apt-get install tesseract-ocr`.
- נמצא אוטומטית ב-PATH או ב-`C:\Program Files\Tesseract-OCR`. אחרת: `TESSERACT_CMD=` ב-`.env`.

## מה צריך ב-`.env`

```
GEMINI_API_KEY=...
ANTHROPIC_API_KEY=...
```

**חשוב:** מפתח Gemini חייב להיות בפרויקט **עם חיוב פעיל**. בשכבה החינמית יש 20 בקשות
ביום בלבד, ו-Google רשאית להשתמש בתוכן הנשלח.

זה הכול. שאר ההגדרות ב-[.env.example](.env.example) הן אופציונליות עם ברירות מחדל סבירות.
**המפתח דורש יתרת קרדיט פעילה** ב-https://platform.openai.com/billing — בלעדיה
כל קריאה נכשלת והמערכת תציג זאת כהודעה ברורה במסך.

## איך זה עובד

```
גרירת קבצים (כמה שרוצים, תמונות ו/או PDF)
   └─> בדיקת סוג לפי בייטים, לכל קובץ בנפרד   backend/app/files.py
   └─> כל הקבצים משוטחים לרשימת טפסים אחת     backend/app/pipeline.py
   └─> רינדור כל עמוד ל-PNG                   backend/app/pages.py
   └─> שער איכות: רזולוציה נמוכה → אזהרה גלויה     backend/app/pipeline.py
   └─> שני שופטים במקביל, כל אחד לבד:
         gemini-3.8-flash                         backend/app/providers/gemini_vision.py
         claude-sonnet-5-5                        backend/app/providers/claude_vision.py
         (או gpt-5.4-mini — שורה אחת ב-.env)        backend/app/providers/openai_vision.py
   └─> השוואה: ערך רק כששניהם מסכימים              backend/app/consensus.py
   └─> בדיקות דומיין וסימון כתום              backend/app/validators.py
   └─> תיקון אנושי בטבלה                      PATCH /api/records/{id}
   └─> ייצוא Excel מאותם נתונים שנבדקו        backend/app/excel.py
```

| קובץ | תפקיד |
|---|---|
| [backend/app/fields.py](backend/app/fields.py) | שבעת השדות — **מוגדרים פעם אחת**, הפרומפט והאקסל נגזרים מכאן |
| [backend/app/prompts/extract_v1.md](backend/app/prompts/extract_v1.md) | הפרומפט. כאן משפרים את איכות הקריאה |
| [backend/app/providers/base.py](backend/app/providers/base.py) | החוזה. מודל אחר = מתאם חדש, בלי לגעת בשאר הקוד |
| [backend/app/providers/openai_vision.py](backend/app/providers/openai_vision.py) | הקובץ **היחיד** שמייבא SDK של ספק |
| [backend/app/api.py](backend/app/api.py) | ה-API |
| [backend/app/web/index.html](backend/app/web/index.html) | הממשק כולו — דף אחד, ללא build |

## כללים שהמערכת שומרת

- **מספרים הם מחרוזות.** אפסים מובילים נשמרים, גם בתא ב-Excel.
- **שדה שלא נקרא נשאר ריק ומסומן כתום.** המודל מונחה להעדיף `null` על ניחוש.
- **כתום = צריך בדיקה**, כולל ערך חסר. ירוק = אדם תיקן או אישר. אין טענת נכונות אוטומטית.
- **תאריך קבלה בלבד** מחותמת "התקבל" — לא הפקה, לא לידה, לא תוקף.
- **גורם שולח ≠ נותן השירות.** הקופה ששלחה, לא בית החולים שמבצע.
- ערכים מרובים נשמרים כולם, מופרדים ב-`|`, בלי מיון ובלי מכפלות.
- ערך שמתחיל ב-`=`, `+`, `-` או `@` נכתב כטקסט ולא ירוץ כנוסחה ב-Excel.
- תוכן המסמך הוא מידע, לא הוראה למודל.

## מגבלות ידועות

- **אין בסיס נתונים.** הכול בזיכרון; הפעלה מחדש של השרת מוחקת את האצוות.
- **עמוד = טופס.** טופס רב־עמודי או שני טפסים בעמוד עדיין לא נתמכים.
  תמונה אחת = טופס אחד; PDF = מספר העמודים שבו.
- **30 טפסים לגרירה** כברירת מחדל (`MAX_PAGES_PER_BATCH` ב-`.env`). התקרה היא
  על הגרירה כולה, כי כל טופס הוא קריאה בתשלום למודל.
- **אין מדידת דיוק.** לא נבדק כמה מהשדות נקראים נכון.

## מדידה

```powershell
uv run evaluate          # מציג תוכנית ועלות משוערת — לא מוציא כסף
uv run evaluate --yes    # מריץ בפועל על הטפסים שנשמרו כמאומתים
```

## בדיקות

```powershell
uv run pytest -q
```

90 בדיקות, ללא קריאות רשת. מכסות זיהוי סוג קובץ, אפסים מובילים, תאריכים,
ערכים מרובים, נטרול נוסחאות, כשל ספק, וריבוי קבצים — כולל שלוש בדיקות שמוודאות
ש-3 תמונות, PDF אחד עם 3 עמודים, ותמונה עם PDF של 2 — כולם נותנים 3 שורות.
